SANITISATION

This package is written for a public repository. It contains no server account
name, host name, alias, network address, directory path, run identifier,
credential, token, secret, environment value, database connection string,

because in this release those are exactly the values the owner's authorisations
were bound to. The only long identifiers are Git hashes in the owner's own
public repository and GitHub pull-request, run and comment numbers.
