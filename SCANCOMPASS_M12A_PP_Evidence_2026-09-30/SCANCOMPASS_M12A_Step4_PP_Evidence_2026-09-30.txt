PURPOSE
Move production scan execution out of the web assessment process and through the private scanner
worker boundary while keeping scoring/report composition web-side.

IMPLEMENTED
- Created server-only app-side worker HTTP client.
- Created shared pure worker endpoint constants.
- Production endpoint fixed to scanner:8787, POST /scan, application/json.
- Client accepts a worker command, not an arbitrary URL.
- No redirects.
- Worker response is bounded, parsed, strictly schema-validated and executionId-correlated.
- One executionId now correlates admission log -> worker command -> worker log -> result ->
  completion log.
- productionCapabilities deleted from web orchestration.
- AssessmentCapabilities deleted.
- AssessmentContext.capabilities deleted.
- AssessmentContext.newExecutionId deleted; execution ID ownership moved to admission.
- Web-side runAssessment no longer constructs scanner network transports/resolvers/RDAP/TLS probes.
- Scoring and report composition remain web-side and still execute exactly once.
