6. REAL BACKUP AND RESTORE COVERAGE

The M12B-6 drill was extended to M12C and uses REAL dump and restore inside
the disposable container, with the application role for every application
operation. Before the dump it establishes a live session, a live reset
challenge, a pending signup, a PENDING DOMAIN CHALLENGE and a CURRENT DOMAIN
AUTHORISATION; after the dump all five are spent or revoked and shown dead.

  unsanitized restore (positive control)  every one of the five comes back to
                                          life, including the domain
                                          authorisation and a challenge
                                          completed with the backup-time proof
  sanitized restore                       a five-statement invalidation in one
                                          application-role transaction kills
                                          all five; a second run deletes
                                          nothing; a fresh login and a fresh
                                          domain verification still work;
                                          account, credential and report
                                          content digests unchanged
  partial-failure injection               a failure after the fourth statement
                                          commits NONE of the five
  omission testing                        omitting EACH of the five, on its own
                                          fresh restore, leaves exactly the
                                          matching capability usable

The drill passed 41/41 in every one of the twenty runs in section 8. Five
mutations of its sanitized transaction were each detected, and renaming one
critical check made the acceptance runner REFUSE the report rather than pass
it. [S5,S6]

7. THE TEST-HELPER DEFECT, RE-MEASURED

A test helper in PR #17 replaced the merged authorisation row instead of
overriding one field, so every override case was being refused for the wrong
reason. Seven mutations of the authorisation module were re-measured against
both test suites, with the source restored after each:

  mutation                            PR #17 tests    current tests
  remove the expiry check             0 failed        3 failed
  expiry inclusive-valid              0 failed        2 failed
  remove the method check             0 failed        2 failed
  remove the exact-domain comparison  0 failed        3 failed
  a parent row authorises a subdomain 0 failed        1 failed
  clock read before the DB read       0 failed        1 failed
  remove the account-state check      1 failed        1 failed

Six of seven mutations had been UNDETECTED. The new test-only commit adds a
guard that the helper changes only the field an override names, one-field-away
pairs so each refusal can come only from its named field, and fail-closed
uncertainty cases covering every indeterminate resolver code. Reverting the
helper to the replacing shape now fails four tests immediately. [S5]
